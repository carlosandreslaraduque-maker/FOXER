# 🦊 FOXER - Preparación ICFES

Aplicación web interactiva estilo Duolingo para preparar a estudiantes de grado 11 para las Pruebas Saber 11.

## Tecnologías
- HTML5, CSS3, Vanilla JavaScript
- PHP (Backend)
- MySQL (Base de Datos)

## Cómo ejecutar el proyecto localmente
1. Clona este repositorio.
2. Mueve la carpeta a `C:\xampp\htdocs\`.
3. Enciende Apache en XAMPP.
4. Abre `http://localhost/foxer-app` en tu navegador.
5. (Opcional para el registro) Importa el archivo `.sql` en MySQL Workbench.
